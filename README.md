## Featured projects

### [SEC Filings RAG Intelligence](https://github.com/Alif1642/sec-filings-rag-intelligence)

An evidence-oriented research system for finding and analyzing information in SEC 10-K and 10-Q filings. It combines BM25 and FAISS retrieval with reciprocal-rank fusion and cross-encoder reranking, while using SEC XBRL Company Facts for deterministic financial calculations.

`Python` `RAG` `BM25` `FAISS` `FastAPI` `Streamlit` `Docker` `pytest`

### [Retail Demand Forecasting & Inventory](https://github.com/Alif1642/retail-demand-forecasting-inventory)

An end-to-end retail forecasting workflow built on M5 Walmart data. It uses leakage-safe lag and rolling features, LightGBM, chronological and rolling-origin validation, uncertainty intervals, and inventory-oriented decision outputs.

`Python` `LightGBM` `Time Series` `FastAPI` `Streamlit` `Docker` `CI`

### [Real-Time Transaction Fraud Risk & Monitoring Platform](https://github.com/Alif1642/real-time-fraud-risk-platform)

A transaction-risk platform designed for real-time scoring, threshold-based decisions, SHAP explanations, experiment tracking, drift monitoring, API serving, and an analyst-facing dashboard.

`Python` `Machine Learning` `FastAPI` `MLflow` `Evidently` `SHAP` `PostgreSQL` `Docker`

### [AI-Based Real-Time Traffic Violation Detection](https://github.com/Alif1642/ai-traffic-violation-detection)

A Streamlit video-analysis application that tracks road vehicles with YOLO, detects license plates, applies OCR, estimates pixel-motion speed, flags configured speed and lane rules, and exports annotated video and event data.

`Python` `YOLOv8` `OpenCV` `EasyOCR` `Object Tracking` `Streamlit`

### Chicago Payroll Data Analysis

A reproducible analysis of public payroll data covering cleaning, SQL exploration, compensation patterns, and decision-focused visualization.

`Python` `Pandas` `SQL` `EDA` `Data Visualization`
